## Features
1. Create Student - Register students with parent details
2. All Students - View and export student list
3. Create Subject - Add subjects for specific classes
4. Create Class - Manage school classes
5. Create Result - Enter marks and generate grades
6. Invoice - Create fee invoices
7. Report - Generate class performance reports
8. Payment - Record fee payments

## How to Build
1. Push code to GitHub repository
2. GitHub Actions will automatically build the EXE
3. Download installer from Actions artifacts
