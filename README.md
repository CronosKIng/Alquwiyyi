## How to Use
1. First create a Class (Create Class menu)
2. Then create Students (Create Student menu)
3. Create Subjects for each class
4. Enter Results and get automatic grades

## Features
- Student registration with parent details
- Class management
- Subject management
- Result entry with automatic grading (A-F)
- Division calculation (1-4)
- Report generation
- Payment and Invoice tracking
- Export to Excel
